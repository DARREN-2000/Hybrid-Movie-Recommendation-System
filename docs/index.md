# Hybrid Movie Recommendation System

Welcome to the documentation for the Hybrid Movie Recommendation System.

This system uses a dual-approach (Content-Based and Collaborative Filtering) via Scikit-Learn to deliver fast, highly relevant movie recommendations, wrapped in a beautiful Streamlit UI.
