# Support

We want to ensure you have a great experience using this project. If you need help, here are the best ways to get it.

## 1. Documentation
The primary source of support is our documentation. Please check the `docs/` directory or the main `README.md` before opening an issue.

## 2. GitHub Issues
If you have found a bug or have a feature request, please open an issue on GitHub.
*   **Bug Reports:** Please provide a clear description of the problem, steps to reproduce it, and your environment details.
*   **Feature Requests:** Clearly describe the feature, the use case, and why it would be beneficial to the project.

## 3. GitHub Discussions
For questions about how to use the project, architectural discussions, or general advice, please use GitHub Discussions (if enabled on the repository).

## Community Support
This is an open-source project maintained by volunteers. While we strive to be responsive, please understand that support is provided on a best-effort basis.
